# Evidence worksheet

Load when comparing several papers or reconciling conflicting results. Keep one row per experiment or claim, not only one per paper.

| Field | What to record |
| --- | --- |
| Question | The user question this evidence addresses |
| Source | Title, stable URL/DOI/arXiv ID, version and retrieval date |
| Access | Full text, selected sections or abstract only |
| Claim | Exact conclusion being evaluated, paraphrased |
| Location | Section/table/figure/page supporting it |
| Setting | Dataset, split, sample size, model and harness versions |
| Comparator | Baseline and differences besides the tested change |
| Measurement | Metric, denominator, units, uncertainty and run count |
| Resources | Latency, tokens and monetary cost when actually reported |
| Limits | Confounds, missing data, exclusions and external validity |
| Status | Supports, qualifies, contradicts or does not address the claim |

Do not sum sample sizes across overlapping datasets or average incomparable metrics. Distinguish reported results from experiments you reproduced. Resolve disagreements by comparing definitions and conditions; leave incompatible evidence separate when no fair common scale exists.

## Español

Registra pregunta, fuente/versiones, acceso real, ubicación, condiciones, comparador y métrica. No mezcles experimentos incompatibles ni presentes resultados publicados como pruebas ejecutadas por Fénix.
