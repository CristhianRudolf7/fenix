# Search evidence and AI citations

For a discoverability audit, separate crawl access, indexing eligibility, retrieved content, displayed citation and subsequent user action. Check the final response and rendered content, not only a source template. Record actual canonical URLs, content freshness and the sources of substantive claims.

For AI visibility, freeze a relevant query set and record engine/mode, date, language/location, account context when material, cited URLs and whether the claim was attributed correctly. Count a brand mention separately from a linked citation. Repeated observations reduce dependence on one response; they do not establish causality for a page edit. Keep screenshots/raw results where permitted and compare like conditions.

Use current primary documentation for engine-specific requirements. Google's guidance states no special AI file or schema is required for its AI search features. Do not generalize this to every engine or claim that `llms.txt`, a preferred paragraph length or invented statistics guarantee citations. Produce accessible, useful content with verifiable evidence and markup matching what users see.

For Search Console or another analytics connector, identify the property type, account, date range, timezone, dimensions and aggregation. A URL-prefix property and a domain property are different targets. Bounded top rows may omit low-volume queries; pagination does not remove Search Console's internal limits or guarantee every row. Do not call their sum a complete total. Record data latency, filters and privacy/sampling limits. A connector name does not establish which provider API it calls.

Primary references: [Google AI features and websites](https://developers.google.com/search/docs/appearance/ai-features) and [Search Analytics query limits](https://developers.google.com/webmaster-tools/v1/searchanalytics/query). Recheck current provider documentation when executing a task.

## Español

Separa acceso, indexación, citas y conversiones. Compara consultas con motor, fecha y contexto registrados. Verifica propiedad y límites de los datos analíticos; las filas principales pueden ser parciales. No prometas citas por archivos especiales o cambios de estilo.
