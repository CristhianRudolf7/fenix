# Retrieval practice / Práctica de recuperación

For requested cards, choose a small testable fact or distinction per prompt, with enough context to have an unambiguous answer. Preserve source/page identity and flag uncertain source claims. Avoid answer leakage, vague multi-part questions and cards that require guessing the author's intended phrasing. Include application or discrimination cases when the goal is understanding, not only recognition.

Inspect the existing deck, note model, fields, tags and duplicate policy before importing. Anki notes and cards differ: one note may generate several cards. Preserve existing note IDs and scheduling history when correcting content. Do not reset intervals, mass-delete notes or overwrite templates merely to add study material. Use the configured AnkiConnect API only if actually available; inspect its supported actions and returned errors.

Without a connection, prepare a compatible import file and state that it has not been imported. Escape delimiters and markup according to the chosen format, and verify a small representative import when the destination is available. A supplied deck request does not authorize automatic reminders or a new study schedule. Adapt practice from demonstrated recall and confusion; do not promise a universal retention percentage.

ES: crea preguntas precisas con fuente, conserva IDs e historial de repaso y distingue nota de tarjeta. Un archivo de importación preparado no implica que se haya actualizado Anki.
