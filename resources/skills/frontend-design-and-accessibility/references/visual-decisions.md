# Visual decisions and comparison

Use for a redesign or new visual direction, not every component edit.

Read the current product, audience, content and brand constraints. Choose hierarchy, typography scale, content density, spacing, color roles and image treatment that serve the task. An operational dashboard can need dense aligned data; an editorial page can need a quieter reading rhythm. Neither asymmetry nor a particular font is a universal upgrade.

Use existing assets and tokens first. For a new direction, build one representative section or screen with realistic content and all relevant states before propagating it. Make the intended primary action legible. Align comparable labels, values and controls; avoid replacing useful tables with decorative cards. Check the longest actual labels and localized copy rather than a short English placeholder.

Capture before and after with the same viewport, content, theme, identity and state. Inspect the rendered result: font fallback, wrapping, overflow, contrast, focus, error placement and whether the most prominent elements serve the intended flow. An image can establish appearance but cannot prove interaction or accessibility. Distinguish untested states and taste judgments from observed defects.

Keep stock/generated/demo assets and sample numbers identifiable. Never fabricate testimonials, customers, performance figures or publication dates to make a design appear authentic. Generate raster assets only when they serve the brief; use semantic HTML and real components for usable controls. Preserve the owner's requested palette, system and density unless a specific accessibility or functional defect requires a correction.

Deliver the implemented change with representative evidence and limitations. Avoid unvalidated numerical design scores or mandatory redesign ceremonies for a small fix.

## Español

Elige jerarquía, tipografía y densidad según el uso real y la marca. Compara vistas con iguales datos, estado y tamaño. Verifica legibilidad, interacción y estados; separa preferencias estéticas de fallos. No inventes pruebas sociales ni cifras para dar apariencia de autenticidad.
