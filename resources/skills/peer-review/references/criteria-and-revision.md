# Review criteria and revision checks / Criterios y comprobación de revisiones

Bind findings to the manuscript type and actual venue or user criteria. Separate internal validity, external validity, contribution and presentation; a polished rewrite can improve presentation without fixing scientific support. Record the passage, claimed consequence, supporting evidence and a bounded corrective request. Unknown data access is a limitation, not proof of fabrication.

When checking a revision, compare the previous finding with the actual changed passage and evidence, not only the author's response letter. Retain unresolved items and newly introduced contradictions. Distinguish advisory author feedback from an official editorial decision; the agent cannot assign journal authority to its simulated review.

Multiple perspectives do not establish statistical independence, especially with the same model, inputs or earlier conclusions. For a requested calibration, use an independently labeled set with soundness-changing and presentation-only controls, count misses and false alarms, and state the limited sample. Do not label routine live reviews calibrated without a validated application procedure.

ES: vincula críticas a criterios y evidencias concretas. Comprueba el cambio real al revisar una respuesta; no confundas buena presentación con validez científica ni varias perspectivas con independencia demostrada.
