# Maintaining a skill library

Use for a requested catalog audit or comparison with an external collection. Inventory canonical entrypoints separately from translations, platform adapters, command aliases and fixtures. A large count does not demonstrate distinct capabilities or model quality.

For each candidate, record intended outcome, prerequisites, affected existing skill, review depth and decision: retain, improve, add a distinct procedure, or defer an unsupported capability. Discovery descriptions and headings can support a catalog map; adoption requires reading the relevant procedure and executable dependencies. Do not call inventory, hashing or keyword scans full-text review.

Track content hashes for entrypoints and supporting resources, not only modification times. Include added/deleted files and dependency changes when deciding what to reread. Preserve a previous verdict with its original evidence and scope; unreadable or missing files make coverage incomplete. Linked external tools require their own source/capability review before execution.

Usage data can help prioritize, but an absent event or low frequency is not proof that a specialist skill is useless. Check callers, user customization, activation state and boundary queries before proposing a merge/removal. Prefer aliases for synonyms and conditional references for depth. Do not turn a library audit into deletion of user files or global policy changes.

Evaluate successful outcomes separately from observed instruction compliance. A model-generated scenario and model-generated grading rubric can share the same mistake. Freeze independent task evidence and score acceptable alternative methods fairly; neither a required heading nor a sequence of tool names proves the artifact is correct. Retain failure and unrelated-task cases.

## Español

Cuenta capacidades canónicas y separa traducciones o adaptaciones. Registra profundidad de lectura, decisión y huellas de todos los recursos. No retires skills por falta de registros de uso ni confundas seguimiento de instrucciones con resultados correctos.
