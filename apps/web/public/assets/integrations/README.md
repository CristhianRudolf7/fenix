# Integration icons / Iconos de integraciones

Google, GitHub, Telegram, WhatsApp, PostgreSQL and SQLite SVGs come from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons); Slack comes from its 14.0.0 release. The accompanying CC0 license is preserved. Colors are applied locally. Brand names and marks belong to their respective owners.

Assets are served by Fénix itself; displaying icons makes no external requests. Microsoft and generic capability symbols are defined in the local React components.

Los SVG se sirven desde Fénix, sin solicitudes externas. Se conserva la licencia CC0 de Simple Icons; las marcas pertenecen a sus respectivos titulares. Microsoft y los símbolos de capacidades están definidos en los componentes locales.
