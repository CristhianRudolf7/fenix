Every canonical entry is accounted for. “Covered” is an outcome-level match, not implementation/API parity. Full-entrypoint review is distinguished from catalog screening; neither implies an executable security audit.

Cada entrada canónica tiene una decisión. La correspondencia por finalidad no implica igualdad de implementación. Se distingue lectura íntegra del archivo de instrucciones de revisión de catálogo; ninguna equivale a auditar todo el código ejecutable.
